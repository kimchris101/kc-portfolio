KIM CHRIS — FRONTEND DEVELOPER & UI/UX DESIGNER PORTFOLIO 🚀

A modern, responsive, high-contrast multipage portfolio website inspired by the GitHub dark theme aesthetic (dark blues, neon cyan, and magenta). Built with HTML5, CSS3, JavaScript, and Bootstrap 5. ✨

# ==================================================
🌐 LIVE DEMO

Check out the live deployment on GitHub Pages:
👉 https://.github.io/portfolio/

# ==================================================
🌟 FEATURES

• 🎨 GitHub Dark Palette Aesthetic: Deep background tones (#0d1117), dark card containers (#161b22), and vibrant neon cyan and magenta accent highlights.

• 📂 Multipage Architecture: Clean separation of concerns with dedicated pages (Home, About, Work, Contact).

• 👁️ Accessible & High-Contrast Typography: WCAG AAA-compliant text contrast for effortless legibility across all forms, card components, and body copy.

• 🖼️ Dynamic Project Highlights: Live screenshot previews embedded directly into modern project cards.

• 🛡️ Custom Avatar Integration: Customized graphic badge showcasing personal branding on the About page.

• 💬 Interactive Contact Interface: High-visibility input fields and interactive feedback logic.

# ==================================================
⚙️ LOCAL DEVELOPMENT SETUP

1. Clone the repository:
git clone [https://github.com/](https://github.com/)/portfolio.git
2. Navigate into the project directory:
cd portfolio
3. Open with VS Code:
code .
4. Launch Preview:
Open index.html with VS Code's Live Server extension or directly in your web browser.

# ==================================================
📦 DEPLOYING TO GITHUB PAGES

1. Commit and push your changes:
git add .
git commit -m "Finalize multipage portfolio and documentation"
git push origin main
2. Navigate to your repository on GitHub.com.
3. Go to Settings > Pages.
4. Under Build and deployment, set Source to "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then click Save.
